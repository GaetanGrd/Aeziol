# Code de conduite

La communauté Aeziol doit rester accueillante, curieuse et respectueuse, quels que soient l’expérience, l’identité, l’origine, la langue ou le niveau de maîtrise technique des participants.

## Comportements attendus

- critiquer les idées et le code sans attaquer les personnes ;
- expliquer les désaccords avec des faits reproductibles ;
- respecter la vie privée et ne jamais republier de journaux ou données personnelles ;
- accepter qu’une proposition puisse être refusée pour des raisons de sûreté, de portée ou de maintenance ;
- aider les nouveaux contributeurs à comprendre le contexte.

## Comportements inacceptables

- harcèlement, intimidation, insultes ou discrimination ;
- publication d’informations privées ou de secrets ;
- contenu sexuel, violent ou volontairement perturbateur ;
- spam, manipulation ou exploitation des systèmes d’autrui ;
- poursuite d’un comportement après une demande claire d’arrêt.

## Application

Le mainteneur peut modifier ou supprimer un contenu, fermer une discussion, refuser une contribution ou limiter la participation afin de protéger le projet et ses participants. Les incidents peuvent être signalés discrètement via le profil GitHub du mainteneur. Les signalements de sécurité suivent [SECURITY.md](SECURITY.md).
